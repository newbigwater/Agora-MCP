# Agora-MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify `agora-mcp`, an open-source Model Context Protocol (MCP) server enabling asynchronous messaging, coordination, and adversarial peer review workflows across Claude Code, Antigravity (agy), and OpenAI Codex with local SQLite persistence.

**Architecture:** FastMCP server in `src/agora_mcp/server.py` exposing 6 core MCP tools (`post_message`, `read_messages`, `list_channels`, `request_review`, `submit_review`, `get_review_status`), backed by Pydantic v2 schemas in `models.py` and SQLite persistence in `storage.py` with WAL mode and custom DB path support.

**Tech Stack:** Python 3.10+, `mcp` (FastMCP 1.30+), `pydantic` v2, SQLite (built-in `sqlite3`), `pytest`.

**Spec:** User specification for Agora-MCP hub, messaging tools, review workflow, and multi-CLI agent registration guides.

## Global Constraints

- **Python Version:** 3.10+ (current system: 3.13.14).
- **Core Dependencies:** `mcp>=1.3.0`, `pydantic>=2.0.0`, `pytest>=8.0.0`.
- **Database:** Pure local SQLite (`~/.agora/agora.db` default, overridden by `AGORA_DB_PATH` env var or parameter) with zero external database or API key dependencies.
- **Tool Names & Signatures:** Exact match to spec:
  - `post_message(sender: str, channel: str, content: str, reply_to: Optional[str] = None) -> dict`
  - `read_messages(channel: str, limit: int = 10, unread_only: bool = False, agent_id: Optional[str] = None) -> list[dict]`
  - `list_channels() -> list[dict]`
  - `request_review(requester: str, target_agent: str, title: str, content_diff_or_path: str) -> dict`
  - `submit_review(review_id: str, reviewer: str, verdict: str, comments: str) -> dict`
  - `get_review_status(review_id: str) -> dict`
- **Git Commit:** Final initial commit message: `feat: initial agora-mcp server implementation`.

---

## Review Focus

1. **Invalid Review Verdict:** Verdicts outside `PASS`, `REVISE`, `FAIL` (case-insensitive) raise a clear `ValueError` or return a validation error without corrupting review state.
2. **Non-Existent Review ID:** Querying or submitting a review for a non-existent `review_id` returns an informative error or raises a `KeyError` / `ValueError`.
3. **Empty Channel Query:** Calling `read_messages` on a channel with no messages returns an empty list `[]` instead of an error or failing channel lookup.
4. **Unread Tracking Isolation:** Marking messages as read by `agent_A` via `unread_only=True` does not mark them as read for `agent_B`.
5. **Database Path Fallback & Concurrency:** Concurrency with SQLite WAL mode handles multi-agent read/write access without locking errors, and creates directory `~/.agora/` if not present.
